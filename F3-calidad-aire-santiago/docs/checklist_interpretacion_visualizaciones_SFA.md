# Checklist de interpretación de visualizaciones - Fase 3

## 1. Propósito del documento

Este documento tiene como propósito aportar un checklist de revisión para interpretar visualizaciones generadas en la Fase 3 del proyecto, enfocada en el análisis de calidad del aire en Santiago de Chile.

La contribución se plantea desde una perspectiva no experta en programación, pero orientada a fortalecer la lectura crítica de gráficos y la trazabilidad de las conclusiones obtenidas a partir de los datos.

## 2. Importancia de interpretar correctamente las visualizaciones

Un gráfico no se interpreta por sí solo. Es necesario revisar si está correctamente construido, si representa adecuadamente los datos y si las conclusiones que se extraen de él son consistentes con la evidencia disponible.

En el caso de datos ambientales, esta revisión es especialmente relevante, ya que una interpretación incorrecta podría llevar a conclusiones apresuradas sobre contaminación, estacionalidad, comportamiento de contaminantes o condiciones de calidad del aire.

## 4. Preguntas para interpretar gráficos de series temporales

Cuando se analicen gráficos en el tiempo, se recomienda revisar:

- ¿Existe una tendencia creciente, decreciente o estable?
- ¿Se observan ciclos diarios, semanales, mensuales o estacionales?
- ¿Hay periodos con aumentos o disminuciones relevantes?
- ¿Los cambios observados podrían estar asociados a estacionalidad?
- ¿Se está comparando el mismo contaminante en el mismo periodo?

## 5. Preguntas para interpretar comparaciones entre contaminantes

Cuando se comparen contaminantes o variables ambientales, se recomienda revisar:

- ¿Las variables comparadas tienen la misma unidad de medida?
- ¿Las escalas utilizadas permiten una comparación justa?
- ¿Se está comparando concentración, promedio, máximo u otra medida?
- ¿La comparación considera el mismo periodo temporal?
- ¿Se explican posibles diferencias entre contaminantes?

## 6. Preguntas para interpretar comparaciones por estación o zona

Cuando se comparen estaciones de monitoreo o zonas geográficas, se recomienda revisar:

- ¿Se identifican claramente las estaciones o zonas comparadas?
- ¿Todas las estaciones tienen datos suficientes?
- ¿El periodo de medición es comparable entre estaciones?
- ¿Existen diferencias relevantes entre zonas?
- ¿Las diferencias podrían explicarse por ubicación, tráfico, actividad urbana u otros factores?
- ¿Se evita generalizar los resultados de una estación a toda la ciudad?

## 7. Riesgos de interpretación visual

Al interpretar visualizaciones de calidad del aire, se deben considerar los siguientes riesgos:

- Interpretar valores puntuales como tendencias permanentes.
- Comparar contaminantes con unidades o escalas diferentes.
- Ignorar datos faltantes o periodos sin información.
- Generalizar resultados de una estación específica a toda la ciudad.
- No distinguir entre promedio, máximo, mínimo o valor instantáneo.
- Usar gráficos sin título, unidad o explicación suficiente.
- Formular conclusiones que no estén directamente respaldadas por el gráfico.

## 8. Recomendaciones para comunicar resultados

Para mejorar la comunicación de los hallazgos, se recomienda:

- Usar títulos claros y descriptivos.
- Explicar brevemente qué muestra cada gráfico.
- Indicar periodo, variable y unidad de medida.
- Acompañar cada visualización con una interpretación breve.
- Separar observaciones objetivas de interpretaciones.
- Declarar limitaciones cuando corresponda.
- Evitar afirmaciones categóricas sin respaldo suficiente.
- Relacionar los hallazgos con el objetivo general del proyecto.

## 9. Aporte al proyecto

Este checklist busca fortalecer la interpretación de visualizaciones en la Fase 3, aportando una herramienta de revisión complementaria al trabajo técnico.
